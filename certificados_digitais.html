Cadastrar certificado
Preencher a partir do arquivo do certificado (.cer, .crt ou .pem). É o arquivo público do certificado: não contém a chave privada nem a senha, e é lido aqui no seu navegador, sem enviar o arquivo a lugar nenhum. Para exportá-lo no Windows: abra o certificado (duplo clique ou certmgr.msc) → Detalhes → Copiar para arquivo → "Não exportar a chave privada" → X.509.

A senha do certificado nunca é guardada pelo sistema. Para certificados A1 você pode guardar o arquivo no cofre (protegido pela senha do próprio certificado) e assinar documentos sem procurar o arquivo a cada vez.

Guardar certificado A1 no cofre

O arquivo continua protegido pela senha do próprio certificado, que o sistema nunca guarda. Aqui ela serve só para conferir, agora, que o arquivo abre e é o certificado certo. Depois, para assinar, basta escolher o certificado na lista e digitar a senha.
