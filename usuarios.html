Como cadastrar um novo utilizador (apenas Master)
  1. Abra o Supabase, projeto ERP_Profissional, e clique em Authentication → Users → Add user → Create new user.
  2. Digite o e-mail e uma senha forte, marque Auto Confirm User e confirme.
  3. Abra SQL Editor → New query, cole o comando abaixo trocando o e-mail e o número da empresa (1 = NanoSignals, 2 = SCEII, 3 = Agenciar), e clique em Run:
    select public.app_vincular_usuario('email@empresa.com.br', 1, 'Administrador');
  4. Deve aparecer uma mensagem começando com OK. Se aparecer ERRO, o e-mail ainda não foi criado no passo 1.
  5. Peça à pessoa para entrar e trocar a senha pela chave no topo da página.
