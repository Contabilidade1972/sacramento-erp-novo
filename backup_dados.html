Backup automático (guardado no servidor)
O sistema faz a cópia sozinho, todo dia às 03:00 (horário de Brasília), quando chega o prazo da frequência escolhida. Os arquivos ficam em um espaço privado, e você baixa quando quiser.
Importante: estes backups ficam no mesmo serviço do banco de dados. Para uma proteção completa, baixe uma cópia de tempos em tempos (botão "Baixar" abaixo, ou o backup manual acima) e guarde fora do sistema, em um HD externo ou pen drive.
Como usar o arquivo
  1. O arquivo .zip baixado tem uma pasta planilhas com um arquivo .csv por tabela. Abra no Excel para consultar.
  2. Também vem o arquivo backup_completo.json, usado para restaurar os dados se algo der errado.
  3. Faça o backup toda semana (ou todo fechamento mensal) e guarde as 3 últimas cópias.
O plano gratuito do banco de dados não faz cópias automáticas por conta própria. Por isso existem o backup manual (acima) e o backup automático configurável (no cartão acima).
